Frontend WordPress

Sito pubblico con tema custom sviluppato in codice: template e contenuti chiave in file versionati, database essenziale (utenti, ordini, dati operativi)

Frontend WordPress "Content-as-Code"

Il sito pubblico è un'installazione WordPress con tema custom sviluppato interamente in codice, senza page builder: template, blocchi e configurazioni sono file versionati, scritti e mantenuti tramite sviluppo assistito da AI. Il database resta così leggero e pulito, contenendo solo gli elementi necessari: utenti, ordini e dati operativi.

Il frontend richiama direttamente gli endpoint REST del gestionale, senza layer headless intermedi:

WordPress

Tema custom file-based: template PHP e blocchi scritti come codice versionato, per deploy controllati e rollback immediati

api

API REST Laravel

Chiamate server-side agli endpoint del gestionale (prezzi, ordini, tracking) con caching locale e gestione errori centralizzata
